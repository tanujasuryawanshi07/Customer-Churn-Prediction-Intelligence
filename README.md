# E-Commerce Customer Churn Intelligence System

# Project Overview

The E-Commerce Customer Churn Intelligence System is a data science and machine learning project designed to analyze customer behavior and predict customer churn.

This project implements an end-to-end data pipeline covering data ingestion, SQL-based data processing, exploratory data analysis, visualization, statistical analysis, machine learning, and automation.

## Features

- Data ingestion using NumPy and Pandas
- SQL database manipulation and data merging
- Automated EDA profiling
- Customer churn analysis
- Interactive data visualizations
- Statistical A/B testing
- Machine learning-based churn prediction
- Feature selection and engineering
- Automated ML pipeline
- Command-line automation using argparse

## Technologies Used

- Python
- NumPy
- Pandas
- SQL / SQLite
- Scikit-learn
- Plotly
- Matplotlib
- ydata-profiling
- Git & GitHub
